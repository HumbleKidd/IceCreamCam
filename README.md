# IceCream Cam 🍦

A premium, fully-featured ice cream themed camera Progressive Web App.

## Features
- 📸 Photo capture with high quality
- 🎥 Video recording
- ⚡ Flash / Torch control (Auto / On / Off)
- 👤 Portrait mode
- 📐 Square & Panorama modes
- 🎨 Ice cream themed filters (Strawberry, Chocolate, Mint, Vanilla, Blueberry, Caramel, Rainbow)
- 🔄 Front / Rear camera switch
- 🔍 Zoom
- ⏱️ Timer (3s / 10s)
- ⬜ Composition grid
- 🖼️ Local gallery with save/delete
- ⚙️ Settings (quality, mirror, haptic)
- 📱 Fully installable as PWA (Add to Home Screen)
- ✨ Beautiful light pastel ice cream aesthetic with smooth animations
- 📳 Haptic feedback

## How to Install
1. Open the app (GitHub Pages or raw index.html in a browser)
2. Tap the Install banner or use browser menu → Add to Home Screen / Install App
3. Enjoy your sweet camera!
